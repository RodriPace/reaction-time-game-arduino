# Reaction Time & Time Estimation Game

## Concept

This project is an Arduino game with two modes:

1. **Time estimation:** a number appears on a one-digit display.
   The player counts that number of seconds mentally and presses
   a button when they think the time has passed. An LCD shows
   the actual time and the difference from the target.

2. **Direction reaction:** one of four LEDs lights up. Each LED
   represents a direction. The player moves the joystick in the
   matching direction as quickly as possible.

The project is designed for people who want to test their
reaction speed and ability to estimate time. Arduino sends the
results to Node-RED, where a dashboard displays and analyses them.
